# Block Blast Бот

Android-приложение, которое само играет в Block Blast: смотрит на экран, просчитывает лучшие ходы и перетаскивает фигуры. Скорость от 1x до 10x.

## Скачать

👉 [blockblast-bot.apk](https://github.com/lemonchickbfdi26-cell/blockblast-bot/releases/download/latest/blockblast-bot.apk)

APK собирается автоматически (GitHub Actions) при каждом изменении кода.

## Как пользоваться

1. Установи APK (разреши установку из неизвестных источников).
2. В приложении нажми **«1. Включить бота»** → найди «Block Blast Бот» в Спец. возможностях (на Samsung: «Установленные службы») → включи.
3. Нажми **«2. Разрешить боту видеть экран»** → «Начать».
4. Открой Block Blast — сверху появится панель бота.
5. Один раз нажми **⚙** и тапни: центр левой верхней клетки поля → центр правой нижней клетки → чуть ниже фигур.
6. Жми **▶**. Кнопка **1x** переключает скорость 1x / 2x / 5x / 10x.

Первые 1–3 хода бот «пристреливается»: выясняет, насколько игра поднимает фигуру над пальцем. Дальше ставит точно.

## Как устроено

- `CaptureService` — запись экрана (MediaProjection)
- `Vision` — распознаёт поле 8×8 и фигуры в лотке
- `Solver` — перебирает порядок и места для фигур (сгорание линий, дырки, место под 3×3 и палки 1×5)
- `BotService` — служба спец. возможностей: панель, калибровка, свайпы
